# 外部数据项目评估：global-stock-data

审查对象：`simonlin1212/global-stock-data`（Apache-2.0，公开仓库；审查日期 2026-11-16）。

## 结论

**不作为 A 股行情主数据源接入。可选择性复用全球宏观/利率事件思路，不引入其整套 Skill。**

该项目定位是面向 AI 编程助手的美股数据工具包，主要数据层包括美股行情、Yahoo K 线、SEC EDGAR、CBOE、FINRA、美国财政部、美联储、BIS、ECB、EIA、BLS 等。其核心股票代码、交易所、申报制度、做空与期权数据均不对应沪深北 A 股。

## 对 FHM-100 的可用部分

| 模块 | 结论 | FHM-100 用途 |
|---|---|---|
| BIS / ECB / Fed 全球利率与汇率 | 可参考，部分官方源有复用价值 | 全球流动性、美元利率、汇率变化的宏观事件背景 |
| 美国财政部 / BLS / EIA 宏观数据 | 可参考 | 识别海外宏观政策与能源事件，不直接产生个股分数 |
| Yahoo 美股 K 线 / 美股筛选 | 不接入 | 不是 A 股行情替代源 |
| SEC EDGAR / Form 4 / 13F | 不接入 A 股主链 | 监管制度和覆盖对象不同 |
| CBOE 期权 / FINRA 做空数据 | 不接入 | 不适用于 A 股 M5/M8 |
| 台湾 TWSE / TPEx | 暂不接入 | 与 A 股主线不同，只有明确跨市场研究需求时再单独评估 |

## 接入边界

1. 不把该仓库包装成 A 股全市场数据源，也不把美股数据混入 A 股横截面排名。
2. 全球宏观数据只进入“全球新闻/宏观事件”层，保留源 URL、发布时间、抓取时间、修订信息和许可等级。
3. 事件只影响事件研究和宏观背景；必须经过事件映射、预期差与 Price-In 检验，不能直接抬高股票分数。
4. 复用前逐个检查官方数据源条款、请求频率、User-Agent 和再分发限制。项目本身明确区分数据源合规等级；不能因为代码 Apache-2.0 就推断上游数据可自由商用。
5. 不复制 233KB 的整份 Skill 文件，也不增加美股专用依赖。

## 当前决定

保持 FHM-100 A 股行情主链不变。优先解决 A 股行情、行业主线、事件映射和 M5 缺失字段；全球宏观层以后按单一官方数据源、单一指标、可追溯事件的方式增量接入。
