# PIT 公司行为账本准入契约

状态：工程原语与离线测试；**尚未接入生产扫描器，也没有任何供应商数据因此升级为 VERIFIED**。

## 目的

PR #36 已禁止用未复权原始收盘价计算跨日收益、突破和回撤。本模块
`src/model/pit_corporate_actions.py` 提供下一层准入契约：只有价格、公司行为事件、
完整覆盖证明三者在统一决策时点均可见，才生成供跨日因子使用的总收益财富指数。

## 必需输入

- 价格：证券、交易日、原始 OHLC、带时区的 `available_time`、来源及修订标识。
- 公司行为：证券、除权日、类型、税前每股现金、旧股对应新股比例、核验状态、
  带时区的 `available_time`、来源及修订标识。
- 覆盖证明：证券、覆盖起止日期、`coverage_status=COMPLETE`、带时区的
  `available_time`、来源及修订标识。

覆盖证明必须覆盖整个价格序列，且其可用时间不晚于决策截止时间。没有公司行为记录
不等于没有公司行为；空事件表只有在独立、完整、可追溯的覆盖证明存在时才可能通过。

## 计算与失败关闭

- 输出以首个价格收盘为基准 100 的总收益财富指数，不是可下单的交易价格。
- 现金分红按税前每股现金计入，送股/拆股按新股比例计入。
- 只支持现金分红、拆股、送股。配股及复杂事件保持拒绝状态，不能猜测。
- 事件日期必须落在价格覆盖区间内；首个价格日发生公司行为时，因缺少前收盘而拒绝。
- 任何相关事件或覆盖证明晚于决策截止时间，整只证券序列拒绝，不静默过滤。
- 原始 OHLC 仍用于执行价格和当日 K 线几何；总收益指数只供跨日收益/突破/回撤。
- 历史回测决策时点早于数据实际抓取时间时必须失败；今天下载的历史事件不能倒填成过去已知。
