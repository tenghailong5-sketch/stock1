# 沪电股份分析技能

## 目标
围绕沪电股份（002463.SZ）生成可核验、可执行但不承诺收益的分析。默认分析时点为最新可获得的A股交易日；所有行情必须标注日期和数据来源。

## 数据获取顺序
1. 最新日线行情、成交额、换手率、涨跌幅及可用的资金数据。
2. 公司公告、定期报告、业绩预告、互动平台及重大事项。
3. AI服务器、交换机、高速网络、PCB/高多层板、CCL、铜箔等产业链新闻与订单/扩产动态。
4. 国内政策、海外科技资本开支与主要客户产业趋势。
5. 同行业可比公司表现及沪电股份相对强弱。

优先使用可追溯的官方披露和可靠行情源。对每项关键数据标注来源、时间和口径。不同来源冲突时明确指出，不擅自拼接。

## 分析流程
1. **市场环境**：判断大盘风险偏好、成长股/科技股风格及短线情绪。
2. **产业主线**：判断AI算力及PCB产业链是否仍为资金主线，区分政策/订单/资本开支催化与纯情绪消息。
3. **公司基本面**：梳理收入、利润、毛利率、订单/产能、客户与产品结构、资本开支和估值；区分已披露事实与推断。
4. **资金与量价**：观察成交额、换手、相对行业强度、趋势结构、放量/缩量及可获得的资金流数据。不得将无法验证的“主力资金”标签当作事实。
5. **技术位置**：分析日线趋势、均线、关键支撑/压力、缺口、波动率和量价配合。若没有可靠K线数据，不输出虚构价位。
6. **催化与风险**：列出未来1—3日及中期催化、潜在利空、估值/业绩兑现风险和逻辑失效条件。
7. **交易判断**：给出买入/持有/观望/减仓之一；若数据不足或赔率不佳，允许明确给出观望，不为凑结论而强行推荐。

## 固定报告格式
- 分析日期与行情截止时间
- 最新价格、涨跌幅、成交额、换手率（注明来源；缺失则写“未取得”）
- 一句话结论：买入 / 持有 / 观望 / 减仓
- 市场环境与行业主线判断
- 公司基本面与最新公告
- 资金、量价和技术结构
- 关键支撑位、压力位（仅在有数据支持时给数值）
- 未来1—3日情景：偏强、震荡、偏弱及触发条件
- 参考买入区间、止损参考、止盈/减仓参考
- 逻辑失效条件与主要风险
- 数据来源及数据缺口

## 数据纪律
- 缺失字段写“未取得/无法核实”，不得编造、不得用0填充。
- 明确区分事实、推断和情景假设。
- 对盘中数据标注采集时间；收盘数据不得冒充实时数据。
- 非交易日说明市场休市，并以最近交易日数据分析。
- 不把技术指标或单一新闻当作确定性预测。
- 不保证收益，不使用“必涨”“稳赚”等表述。
